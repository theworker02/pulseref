# pulseref

Pulse timestamps and ref durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/pulseref/

## Install / run

```bash
git clone https://github.com/theworker02/pulseref.git
cd pulseref
node src/cli.js
node --test
```
